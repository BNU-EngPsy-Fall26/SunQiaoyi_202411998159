# 橘检 · 霉斑检测实验室

农产品霉斑检验场景的信号检测论（SDT）交互作业。使用 HTML、CSS、JavaScript 与 Canvas，所有资源随仓库提供，无 CDN、账号、后端或构建依赖。

## 运行

下载或 clone 整个仓库，双击根目录 `index.html`。该文件会打开 `dist/index.html`；也可直接双击后者。保留 `dist` 内各文件及 `assets/orange.png` 的相对位置。推荐现代 Chrome、Edge 或 Firefox。无需安装 Node.js 或 Python。

需要 HTTP 预览时，可选运行 `python -m http.server 8765 --directory dist`，然后访问 http://localhost:8765 。这不是作业运行的必要步骤。

## 操作

1. 填写参与者编号，选择难度、霉斑概率、检测数量和观察时长。正式检测必须填写编号，同一人保持编号一致，不同人使用不同编号。
2. 可先练习6次，练习固定3个正常与3个霉斑样本，提供即时正误反馈，不进入历史记录。
3. 正式检测每局20、40或60次。注视点450ms后呈现刺激，刺激显示1.0、1.6或2.4秒。图片消失后可按F（未检出霉斑）、J（检出霉斑），也可点击或触摸按钮。提前按键与长按重复事件不计数。
4. 作答不限时。正式模式不给即时正误反馈；记录回答后间隔280ms，进入下一试次。
5. 完成后查看四格表、原始击中率与虚报率、实测d′、c、准确率、逐试次结果，或导出CSV。
6. SDT探索页可调整理论d′和c，观察两类分布与ROC；记录与排名页可查看历史、同条件单轮榜与个人汇总榜。

SDT探索页另含混淆矩阵，横向为真实类别（有信号／无信号），纵向为回答（有／无）。默认显示随d′与c滑块更新的理论条件概率。可选择本机保存的任一正式轮次，显示其原始条件概率或实际次数。概率按真实类别分别归一化，H+M=1、FA+CR=1；四格概率合计为2，不是全样本占比。实际数据不会被理论滑块改写。实际次数合计为本轮总试次数。历史为空时只提供理论模式。

切换标签页会暂停并遮挡样本。返回后需主动继续，重新呈现当前未回答试次。重复呈现次数记录为 `replays`。退出本轮需要确认，未完成轮次不保存。完整记录仅保存在当前浏览器的 localStorage，存储失败时仍可完成实验并导出JSON备份。文件协议下的存储行为因浏览器而异；移动目录也可能改变存储区域。

## 多人排名与跨电脑汇总

进入“记录与排名”，在“同条件排行榜”中操作。

- 比较条件由设置d′、P(S)、观察时长、每轮试次数四项共同决定。20、40、60次各自排名，入门与挑战难度也不混排。
- 单轮榜每条记录是一轮完整正式检测。以未四舍五入的实测d′降序排列，差值不超过1e-10视为同分并列，采用1、1、3的名次格式。界面显示两位小数，因此视觉上相同的值仍可能因未显示的小数位不同而有不同名次。准确率、击中率、虚报率和c仅作为辅助信息显示，c不参与排序。
- 排行榜同时生成ROC散点图。横轴为原始虚报率，纵轴为原始击中率，点内数字为d′排名；左上区域通常表示较好的辨别表现。相同击中率与虚报率的成绩共用一个点，并在图例中分别列出。散点之间不连接，因为不同参与者或不同轮次不是同一观察者在多个判断阈值下形成的ROC曲线。散点位置使用原始比例，d′排序继续使用加0.5校正后的比例，所以图用于直观比较，精确值以表格为准。
- 个人榜按参与者编号分组。可统一要求每人1、2、3或5轮，默认3轮。每人选当前数据里时间最早的K轮，日期相同时按轮次ID排序；不足K轮只显示进度。合并这些轮次的全部回答，汇总H/M/FA/CR后只做一次加0.5校正，再计算d′，不平均各轮d′，不选最好成绩。
- 编号去除首尾空格，并进行Unicode NFKC规范化。不同电脑使用同一编号会合并为同一人，请事先统一分配编号。
- 没有参与者编号的旧记录保留，可查看报告和混淆矩阵，但不进入排行榜。练习不保存、不参赛。
- 完成实验后点击“导出全部记录 JSON”，将各电脑的JSON包集中到一台电脑，在本站“导入记录包”。相同轮次ID且内容一致则跳过；同ID内容冲突或任一记录无效时，整包拒绝，原数据不变。
- 导入会校验参数范围、试次数、真实类别配额和逐试次字段，并重新计算成绩；不采用文件自带的统计值。每包最多2000轮、10MB，合并后最多2000轮。保留所有有效字段中的必要信息，不执行文件中的代码。
- “导出当前榜单 CSV”导出当前条件及榜单类型的成绩，包含参与者、名次、四类次数、d′、c和纳入的轮次ID。结果页的逐试次CSV也包含参与者编号。CSV用于分析，跨电脑汇总须使用完整JSON包。
- 不再自动删除第30轮以前的记录。浏览器存储空间有限，应定期导出JSON；清空历史会同时清空本机榜单。导入更早轮次会改变个人榜所选数据，导入记录后应重新核对名单。

本地记录包可被编辑，用户身份和时间来自本机，不能防止改名、删除较差成绩或更改系统时间。此排行榜适合课堂展示。正式比较应事先规定相同练习量、轮数和设备条件，完整收集每人的记录；重复呈现与设备差异仍会影响可比性。所有操作只在本地进行，无服务器、无账号登录、无自动上传。

## 场景与四类结果

用户扮演柑橘质检员，判断当前橙子的可见特征是否来自模拟霉斑类别。背景果皮纹理、正常色斑构成噪声。真实类别由程序在生成试次时预先确定，与用户回答无关。

|真实状态|报告有霉斑|报告无霉斑|
|---|---|---|
|霉斑样本S|击中H：成功检出|漏报M：异常样本被放行|
|正常样本N|虚报FA：正常样本被误判|正确拒绝CR：正常样本正确放行|

先验概率P(S)可选30%、50%、70%。本轮采用固定配额随机排序，信号数量为 `N × P(S)`，在可选试次数下均为整数；每轮都含两类试次。各试次不是独立的伯努利类别抽样，应按固定配额设计理解。

## 刺激模型与难度

采用一维、等方差高斯模型：

- 正常类别的特征强度 `x ~ N(0, 1)`。
- 霉斑类别的特征强度 `x ~ N(d′设置值, 1)`。
- 入门、标准、挑战的理论d′分别为2.6、1.8、1.0。
- 两类使用完全相同的映射 `strength = 1 / (1 + exp(-1.15 × (x - 1.25)))`，控制灰绿色斑块和绒毛纹理的透明度。斑块位置、纹理随机种子等干扰变量独立于类别，不通过边框、编号或按钮暗示答案。
- 正常样本可能有较强的类似霉斑色斑，霉斑样本也可能特征很弱。这是分布重叠的结果，不应把所有有色斑样本都等同于真实霉斑类别。

理论d′描述的是生成器中潜在特征分布的间隔。视觉渲染、观察时长、视觉加工和用户策略会影响表现，不能把设置值当作用户的实测辨别力。素材及霉斑均用于教学模拟，没有真实食品安全检测效度，也没有通过实验验证视觉辨别阈限。

随机数使用每轮保存的32位种子与Mulberry32生成器；高斯抽样使用Box–Muller变换。CSV保留轮次种子、每个刺激种子与特征值，便于复核。

## SDT计算

原始比例：

- `P(Hit) = H / (H + M)`
- `P(FA) = FA / (FA + CR)`
- `Accuracy = (H + CR) / N`

所有轮次统一采用加0.5的对数线性校正，避免原始比例0或1产生无穷Z值：

- `H* = (H + 0.5) / (H + M + 1)`
- `FA* = (FA + 0.5) / (FA + CR + 1)`
- `d′ = Z(H*) - Z(FA*)`
- `c = -[Z(H*) + Z(FA*)] / 2`

Z是标准正态分位数函数，采用Acklam有理近似。界面显示的击中率和虚报率为未经校正的原始比例，d′和c使用校正比例。结果页展示代入数值。c大于0为偏保守，小于0为偏宽松。界面用 `|c| ≤ 0.10` 标记“接近中性”，是描述约定，不是统计检验。d′允许为负；不会强行截断。

探索页的判断阈值 `k = d′/2 + c`，理论 `P(Hit) = 1 - Φ(k-d′)`，`P(FA) = 1 - Φ(k)`。ROC来自理论模型。单轮数据只提供一个经验点，不能据此声称估计出完整经验ROC曲线。改变P(S)不直接改变给定d′、c下的条件命中率和虚报率。
