## 一、研究问题

本项目关注视觉信息的组织方式如何影响注意选择、搜索效率和数量判断。三个实验分别研究：

1. 清晰的目标边界能否减弱邻近干扰项造成的反应冲突。
2. 按特征对界面项目进行空间分组，能否降低联合搜索成本。
3. 给角度图形增加参照信息，能否降低比例判断误差。

三个改进均以常见界面为应用背景，包括报警列表、监控面板、图标库、仪表和数据图表。

## 三、实验一：Eriksen Flanker 与目标视觉隔离

### 3.1 经典范式

被试判断中央箭头朝向，同时忽略两侧箭头。一致试次中，中央箭头和侧翼箭头指向相同方向；不一致试次中，两者指向相反方向。

示例：

```text
一致：   <<<<<
不一致： >><>>
```

按键映射为：中央箭头向左按 `F`，向右按 `J`。

### 3.2 实验设计

采用 2 × 2 被试内设计。

| 自变量 | 水平 |
| --- | --- |
| 一致性 | 一致、不一致 |
| 显示方式 | 普通排列、目标隔离 |

目标隔离条件给中央箭头添加细边框圆角框。箭头大小、颜色、亮度、中心间距和整体宽度保持不变，避免把间距效应混入改进效果。

练习 8 次。正式实验四个条件单元各 12 次，共 48 次。每个单元的左右反应各占一半。试次顺序随机化，并限制连续相同反应不超过 3 次。

单次流程暂定为：

```text
注视点 400 ms → 空屏 200 ms → 刺激最长 1500 ms
→ 正误反馈 300 ms → 试次间隔 300–500 ms
```

### 3.3 因变量

- 正确试次的中位反应时，单位为 ms。
- 每个条件的正确率。
- 超时比例。

### 3.4 改进思路

目标与干扰项连续排列时容易形成一个知觉整体。目标隔离条件使用独立对象边界标出中央目标，帮助观察者把注意限制在任务相关对象上。该设计可用于密集报警列表、方向指示器和控制面板。

### 3.5 事前预测

**H1，经典效应。** 普通排列中，不一致试次的反应时高于一致试次，正确率低于一致试次。

**H2，改进效应。** 目标隔离条件的 Flanker 干扰效应小于普通排列条件：

```text
(RT不一致 − RT一致)目标隔离
<
(RT不一致 − RT一致)普通排列
```

**H3，辅助预测。** 目标隔离的收益主要出现在不一致试次，对一致试次的反应时影响较小。

### 3.6 数据字段

```text
trial_index, block, congruency, layout, target_direction,
flanker_direction, key, correct, rt, timeout
```

后台实验名：`flanker_grouping`。

## 四、实验二：特征搜索、联合搜索与颜色分区

### 4.1 经典范式

被试在项目阵列中寻找红色三角形，并判断三角形朝左还是朝右。目标始终存在，方向判断用于确认被试确实找到了目标。

特征搜索中，目标具有显著的单一特征。联合搜索中，目标需要通过颜色和形状的组合确定。

### 4.2 实验设计

采用 3 × 2 被试内设计。

| 自变量 | 水平 |
| --- | --- |
| 搜索显示 | 特征搜索、混合联合搜索、分组联合搜索 |
| 集合大小 | 8、24 |

三个搜索显示条件：

1. 特征搜索：红色三角形出现在蓝色圆形中。
2. 混合联合搜索：红色三角形出现在红色圆形和蓝色三角形中，项目混合排列。
3. 分组联合搜索：项目种类和数量与混合条件相同，红色项目和蓝色项目分布在两个空间区域。

分组条件中，红色区域位于左侧或右侧的次数相等。项目位置从统一网格中无放回抽取，并加入小幅位置抖动。混合和分组条件不能改变目标的大小、亮度、轮廓或闪烁状态。

目标朝左按 `F`，朝右按 `J`。练习 6–9 次。正式实验六个条件单元各 10 次，共 60 次。每个单元中左右反应各占一半，连续相同反应不超过 3 次。

### 4.3 因变量

- 正确试次的中位反应时。
- 每个条件的正确率。
- 搜索斜率，单位为 ms/item。

搜索斜率计算为：

```text
(RT集合24 − RT集合8) / 16
```

### 4.4 改进思路

混合联合搜索要求观察者在整个界面中寻找特征组合。颜色分区让观察者先选择相关颜色区域，再在较小的项目集合中搜索目标。该设计可用于监控面板、任务列表和图标选择界面。

### 4.5 事前预测

**H4，经典效应。** 混合联合搜索的反应时随集合大小增加得更明显，其搜索斜率大于特征搜索。

**H5，改进效应。** 分组联合搜索的搜索斜率小于混合联合搜索，差异主要出现在集合大小为 24 时。

**H6，准确率预测。** 集合大小为 24 时，分组联合搜索的正确率高于混合联合搜索。特征搜索预计仍具有最短反应时和最小搜索斜率。

### 4.6 数据字段

```text
trial_index, search_type, set_size, group_side, target_direction,
target_cell, key, correct, rt, timeout
```

后台实验名：`visual_search_grouping`。

## 五、实验三：Cleveland–McGill 比例判断与角度参照线

### 5.1 经典范式

每个试次呈现两个图形值，被试估计较小值是较大值的百分之多少。真实比例控制在 20%–80%，避免极端比例。

### 5.2 实验设计

采用单因素三水平被试内设计。

| 条件 | 显示方式 |
| --- | --- |
| 共同尺度 | 两个水平条形共享 0–100 的起点和尺度 |
| 纯角度 | 两个等半径扇形，无刻度和参考线 |
| 角度改进 | 扇形加入低对比度刻度环和 25%、50%、75% 参考射线 |

被试在输入框中填写 0–100 的整数，并按回车提交。两个目标值、左右位置和较大值所在位置随机化。三种条件使用同一组真实比例，防止材料难度不同。

练习 6 次。正式实验每个条件 12 次，共 36 次。三种显示方式以小区组交错呈现，避免固定的练习或疲劳顺序。

### 5.3 因变量

- 绝对百分比误差。
- 对数误差。
- 判断时间。

计算方法：

```text
绝对误差 = |估计百分比 − 真实百分比|
log error = log2(|估计百分比 − 真实百分比| + 1/8)
```

结果展示以绝对误差为主，对数误差用于与经典研究进行补充比较。

### 5.4 改进思路

纯角度图缺少稳定参照。刻度环和参考射线帮助观察者把角度映射到固定比例区间。该设计可用于仪表、环形进度图和饼图。参考线使用低对比度颜色，避免遮挡数据。

### 5.5 事前预测

**H7，经典效应。** 共同尺度条形的绝对误差小于纯角度条件。

**H8，改进效应。** 角度改进条件的绝对误差小于纯角度条件，但预计仍高于共同尺度条形。

**H9，判断时间预测。** 角度改进条件的判断时间预计短于纯角度条件。考虑到部分被试可能逐格计数，判断时间只作为次要结果，不作为改进成功的唯一标准。

### 5.6 数据字段

```text
trial_index, encoding, value_a, value_b, true_ratio,
estimate, abs_error, log_error, rt
```

后台实验名：`graphical_perception_guides`。

## 六、随机化与平衡规则

- 三个实验的顺序按匿名编号分配到六种顺序。
- 每个实验内部先生成数量完全平衡的试次，再执行随机排列。
- Flanker 每个条件单元的左右目标方向相等。
- 视觉搜索每个条件单元的左右目标方向相等，分组区域左右位置相等。
- 图形比例判断中，较大值的左右位置相等，同一组真实比例在三个显示条件中重复使用。
- 连续相同正确按键不超过 3 次。
- 随机化结果随试次数据保存，确保分析时可以复核。

## 八、主要效应与分析计划

### 8.1 Flanker

对每名被试分别计算四个条件的中位反应时和正确率。

```text
普通排列干扰效应 = RT不一致,普通 − RT一致,普通
目标隔离干扰效应 = RT不一致,隔离 − RT一致,隔离
改进收益 = 普通排列干扰效应 − 目标隔离干扰效应
```

改进收益为正时，方向与 H2 一致。

### 8.2 视觉搜索

对每名被试、每种显示方式分别计算集合大小 8 和 24 的中位反应时。

```text
搜索斜率 = (RT24 − RT8) / 16
分组收益 = 混合联合搜索斜率 − 分组联合搜索斜率
```

分组收益为正时，方向与 H5 一致。

### 8.3 视觉搜索范围模型与可视化

为检验颜色分区是否通过缩小有效搜索范围产生收益，正式收数前固定一个简化的搜索范围模型。设 `N` 为项目数量，`τ` 为逐项检查一个项目的时间成本。模型只预测集合大小增加造成的反应时增量：

```text
特征搜索：ΔRTfeature(N) = 0
混合联合搜索：ΔRTmixed(N) = τ × (N − 8) / 2
分组联合搜索：ΔRTgrouped(N) = τ × (N − 8) / 4
```

混合联合搜索假设平均检查约一半项目。颜色分区把相关颜色项目缩小到约一半，因此分组条件的预测搜索斜率是混合条件的一半。特征搜索预测斜率接近零。

网页将集合大小 8 设为共同起点，并用混合联合搜索的实测增量标定 `τ`。标准化后的事前预测为：

```text
特征搜索 = 0
分组联合搜索 = 0.5
混合联合搜索 = 1.0（标定条件）
```

模型页同时展示虚线预测、实线实测、各被试数据点和分组/混合斜率比。正式分析只纳入 `visual_search_grouping` 记录，排除 `test_` 数据、错误试次、超时试次和反应时小于 150 ms 的试次。先按被试和条件计算中位反应时，再汇总被试内的反应时增量。

模型支持两项检验：

1. 实测搜索成本是否满足“特征 < 分组联合 < 混合联合”的顺序。
2. 分组/混合斜率比是否接近事前预测值 0.5。

模型公式、标准化规则和判定方法在正式收数前固定。正式数据收集后不重新选择模型形式或调整预测值。

模型事前计划提交：`fb36016cd6dc4667169dd3dcb8d78288e623e694`。独立模型页面为仓库根目录的 `model.html`，可在本地选择课程 CSV，数据不会上传到第三方服务。

### 8.4 图形比例判断

对每名被试分别计算三个显示条件的平均绝对误差、中位绝对误差和判断时间。

```text
角度参照收益 = 纯角度平均绝对误差 − 角度改进平均绝对误差
```

角度参照收益为正时，方向与 H8 一致。

### 8.5 报告方式

- 先报告样本量、有效试次数、条件均值或中位数和个体数据点。
- 使用被试内配对差值展示改进方向。
- 样本达到 5 人时，以描述统计和效应方向为主。
- 若样本达到 10 人，可补充配对检验和置信区间，检验结果作为补充证据。
- 与经典论文比较时，重点比较效应方向和条件排序。刺激、设备和样本不同，不把数值差异直接解释为复现失败。
- 不显著结果只说明当前数据证据不足，不解释为效应不存在。

### 10.1 被试完成后的匿名总体对比

每名被试完成三个实验后，结果页会从课程接口读取匿名总体数据，并分别展示三项预先定义的改进收益：

1. Flanker 目标隔离收益，单位为 ms。
2. 视觉搜索颜色分区收益，单位为 ms/item。
3. 图形比例判断参照线收益，单位为百分点。

三项指标均为正值越大，越符合事前预测。图中菱形表示当前被试，圆点表示其他匿名被试，虚线表示同伴中位数。页面同时报告同伴人数、中位数、中间 50% 区间和当前被试在现有样本中的百分位。

接口返回的 `record_id` 用于排除当前被试刚上传的记录，因此“其他匿名被试”不含本次记录。同一匿名编号重复完成时只使用最后一条完整记录。测试记录、试次数不足的记录和不满足事前排除规则的记录不进入比较。百分位仅用于说明当前样本中的相对位置，不作为个人能力评价。

### 10.2 正式收数后的最终数据处理流程

1. 使用下载密钥从课程后台导出原始 CSV 和 JSON，各保留一份只读原件，不覆盖、不手工修正。
2. 排除所有 `test_` 实验；按匿名编号和实验名检查重复记录，每人每个实验保留最后一条完整记录。
3. 核对计划试次数：Flanker 48 次、视觉搜索 60 次、图形比例判断 36 次。记录缺失、条件数量不平衡和字段截断情况。
4. 按第七节的事前规则标记错误、超时、过快反应、低正确率和未完成记录，并在清理日志中保存排除原因。
5. 先按被试计算条件中位反应时、正确率、搜索斜率和绝对误差，再计算三项被试内改进收益。不能先把所有试次混在一起求总体均值。
6. 汇总有效样本量、有效试次数、各条件均值或中位数、个体数据点、改进收益及其方向。样本达到 10 人时补充配对检验和置信区间。
7. 将经典效应方向与原论文或课程材料对照，再判断 H1–H9 是否得到支持。结果不支持预测时保留原预测并如实讨论。
8. 把最终样本量、排除情况、图表、统计结果、原文对照、局限和讨论更新到网页与 README，保留分析日期和使用的代码版本。

### 10.3 正式样本与数据清理

正式数据于 2026-11-08 冻结。三个实验各有 12 名有效被试，合计 1728 个正式试次。每名被试均完成 Flanker 48 次、视觉搜索 60 次和图形比例判断 36 次。数据中没有重复记录、缺失记录、超时或条件数量不平衡。

Flanker 与视觉搜索没有低于 150 ms 的正确试次，也没有被试因正确率低于 60% 被排除。图形比例判断按事前规则排除 3 个低于 300 ms 的试次，另有 3 个失焦试次保留标记。统计分析先计算每名被试的条件指标，再对被试内差值进行双侧单样本 t 检验。置信区间为 t 分布 95% 区间，效应量使用 Cohen's dz。

### 10.4 正式结果与原文对照

完整图表、12 名匿名被试的数据点和 H1–H9 判断见[正式结果页](./results.html)。

#### Flanker 与目标隔离

普通排列的不一致刺激比一致刺激慢 47.3 ms，95% CI [19.3, 75.2]，t(11) = 3.73，p = .003，dz = 1.08。该方向符合 Eriksen 与 Eriksen（1974）报告的反应不兼容侧翼干扰。普通排列和目标隔离的干扰效应分别为 47.3 和 47.3 ms，差值为 −0.08 ms，95% CI [−23.82, 23.66]，p = .994。目标框没有降低干扰，因此 H2 和 H3 未得到支持。H1 的反应时预测得到支持，但一致与不一致条件的正确率均为 97.9%，正确率预测未得到支持。

#### 视觉搜索与颜色分区

特征搜索斜率为 −0.8 ms/item，混合联合搜索为 18.6 ms/item。两者相差 19.4 ms/item，95% CI [11.3, 27.5]，p < .001。结果符合 Treisman 与 Gelade（1980）关于特征搜索近似并行、联合搜索随项目数增加而变慢的预测，H4 得到支持。

颜色分区条件的斜率为 1.4 ms/item，比混合联合搜索低 17.2 ms/item，95% CI [9.83, 24.56]，t(11) = 5.14，p < .001，dz = 1.48。12 名被试的斜率收益方向全部为正。集合大小为 24 时，颜色分区平均缩短 285.6 ms；集合大小为 8 时缩短 10.5 ms。H5 得到支持。大小为 24 时，颜色分区和混合条件的正确率分别为 95.8% 和 98.3%，差异方向与 H6 相反，p = .339，因此 H6 未得到支持。

#### 图形知觉与参照线

共同尺度条形和纯角度条件的平均绝对误差分别为 7.38 和 8.13 个百分点。均值方向符合 Cleveland 与 McGill（1984）将共同尺度位置判断排在角度判断之前的结论，但差值只有 0.75 个百分点，95% CI [−1.18, 2.68]，p = .411。H7 只有方向性支持。

加入参照线后的误差为 8.37 个百分点，比纯角度高 0.24 个百分点，95% CI [−1.98, 1.51]，p = .770。纯角度和参照线条件的中位判断时间分别为 8.03 和 9.02 秒，参照线条件慢 0.99 秒，p = .249。H8 和 H9 均未得到支持。

### 10.5 结论与局限

三项显示改进中，颜色分区获得清晰支持。它明显降低联合搜索的集合大小成本，适合用于项目较多的监控面板或图标列表。目标框和角度参照线没有改善本研究中的主要指标。目标边界可能过于轻微，未能改变中央目标与侧翼刺激的竞争。角度参照线可能增加了视觉元素和读数步骤，抵消了参照信息的帮助。

本研究样本量为 12，实验在不同电脑和浏览器中完成。原文的刺激材料、计时环境和统计指标与本研究并不完全相同，因此原文对照主要用于判断效应方向和条件排序。后续研究可增强目标隔离的空间距离或对象边界，并比较更简洁的单条角度基准线。
