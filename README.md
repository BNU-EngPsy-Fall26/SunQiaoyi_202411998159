## 一、研究问题

本项目关注视觉信息的组织方式如何影响注意选择、搜索效率和数量判断。三个实验分别研究：

1. 清晰的目标边界能否减弱邻近干扰项造成的反应冲突。
2. 按特征对界面项目进行空间分组，能否降低联合搜索成本。
3. 给角度图形增加参照信息，能否降低比例判断误差。

三个改进均以常见界面为应用背景，包括报警列表、监控面板、图标库、仪表和数据图表。

## 二、被试与总体流程

### 2.1 被试计划

- 每个实验至少收集 5 名其他被试的数据。
- 时间允许时计划收集 10 名被试。
- 作者自己的调试记录和预测试记录不进入正式分析。
- 被试只填写昵称或匿名编号，不收集真实姓名、学号、手机号等身份信息。
- 被试需使用带实体键盘的电脑，建议屏幕宽度不低于 1024 px。

### 2.2 实验顺序

三个实验均由每名被试完成。程序根据匿名编号把被试分配到六种实验顺序之一，使顺序尽量平衡：

```text
ABC  ACB  BAC  BCA  CAB  CBA
```

其中 A 为 Flanker，B 为视觉搜索，C 为图形比例判断。实验之间设置可自行继续的休息页。预计总时长为 9–12 分钟。

### 2.3 通用程序

1. 阅读实验说明和知情同意。
2. 填写匿名编号。
3. 完成设备和屏幕检查。
4. 阅读单项实验指导语并完成练习。
5. 完成正式试次。
6. 每完成一个实验，单独上传一次数据。
7. 查看个人结果和匿名总体结果。

练习数据与正式数据分开保存，练习试次不进入分析。

## 三、实验一：Eriksen Flanker 与目标视觉隔离

### 3.1 经典范式

被试判断中央箭头朝向，同时忽略两侧箭头。一致试次中，中央箭头和侧翼箭头指向相同方向；不一致试次中，两者指向相反方向。

示例：

```text
一致：   <<<<<
不一致： >><>>
```

按键映射为：中央箭头向左按 `F`，向右按 `J`。

### 3.2 实验设计

采用 2 × 2 被试内设计。

| 自变量 | 水平 |
| --- | --- |
| 一致性 | 一致、不一致 |
| 显示方式 | 普通排列、目标隔离 |

目标隔离条件给中央箭头添加细边框圆角框。箭头大小、颜色、亮度、中心间距和整体宽度保持不变，避免把间距效应混入改进效果。

练习 8 次。正式实验四个条件单元各 12 次，共 48 次。每个单元的左右反应各占一半。试次顺序随机化，并限制连续相同反应不超过 3 次。

单次流程暂定为：

```text
注视点 400 ms → 空屏 200 ms → 刺激最长 1500 ms
→ 正误反馈 300 ms → 试次间隔 300–500 ms
```

### 3.3 因变量

- 正确试次的中位反应时，单位为 ms。
- 每个条件的正确率。
- 超时比例。

### 3.4 改进思路

目标与干扰项连续排列时容易形成一个知觉整体。目标隔离条件使用独立对象边界标出中央目标，帮助观察者把注意限制在任务相关对象上。该设计可用于密集报警列表、方向指示器和控制面板。

### 3.5 事前预测

**H1，经典效应。** 普通排列中，不一致试次的反应时高于一致试次，正确率低于一致试次。

**H2，改进效应。** 目标隔离条件的 Flanker 干扰效应小于普通排列条件：

```text
(RT不一致 − RT一致)目标隔离
<
(RT不一致 − RT一致)普通排列
```

**H3，辅助预测。** 目标隔离的收益主要出现在不一致试次，对一致试次的反应时影响较小。

### 3.6 数据字段

```text
trial_index, block, congruency, layout, target_direction,
flanker_direction, key, correct, rt, timeout
```

后台实验名：`flanker_grouping`。

## 四、实验二：特征搜索、联合搜索与颜色分区

### 4.1 经典范式

被试在项目阵列中寻找红色三角形，并判断三角形朝左还是朝右。目标始终存在，方向判断用于确认被试确实找到了目标。

特征搜索中，目标具有显著的单一特征。联合搜索中，目标需要通过颜色和形状的组合确定。

### 4.2 实验设计

采用 3 × 2 被试内设计。

| 自变量 | 水平 |
| --- | --- |
| 搜索显示 | 特征搜索、混合联合搜索、分组联合搜索 |
| 集合大小 | 8、24 |

三个搜索显示条件：

1. 特征搜索：红色三角形出现在蓝色圆形中。
2. 混合联合搜索：红色三角形出现在红色圆形和蓝色三角形中，项目混合排列。
3. 分组联合搜索：项目种类和数量与混合条件相同，红色项目和蓝色项目分布在两个空间区域。

分组条件中，红色区域位于左侧或右侧的次数相等。项目位置从统一网格中无放回抽取，并加入小幅位置抖动。混合和分组条件不能改变目标的大小、亮度、轮廓或闪烁状态。

目标朝左按 `F`，朝右按 `J`。练习 6–9 次。正式实验六个条件单元各 10 次，共 60 次。每个单元中左右反应各占一半，连续相同反应不超过 3 次。

### 4.3 因变量

- 正确试次的中位反应时。
- 每个条件的正确率。
- 搜索斜率，单位为 ms/item。

搜索斜率计算为：

```text
(RT集合24 − RT集合8) / 16
```

### 4.4 改进思路

混合联合搜索要求观察者在整个界面中寻找特征组合。颜色分区让观察者先选择相关颜色区域，再在较小的项目集合中搜索目标。该设计可用于监控面板、任务列表和图标选择界面。

### 4.5 事前预测

**H4，经典效应。** 混合联合搜索的反应时随集合大小增加得更明显，其搜索斜率大于特征搜索。

**H5，改进效应。** 分组联合搜索的搜索斜率小于混合联合搜索，差异主要出现在集合大小为 24 时。

**H6，准确率预测。** 集合大小为 24 时，分组联合搜索的正确率高于混合联合搜索。特征搜索预计仍具有最短反应时和最小搜索斜率。

### 4.6 数据字段

```text
trial_index, search_type, set_size, group_side, target_direction,
target_cell, key, correct, rt, timeout
```

后台实验名：`visual_search_grouping`。

## 五、实验三：Cleveland–McGill 比例判断与角度参照线

### 5.1 经典范式

每个试次呈现两个图形值，被试估计较小值是较大值的百分之多少。真实比例控制在 20%–80%，避免极端比例。

### 5.2 实验设计

采用单因素三水平被试内设计。

| 条件 | 显示方式 |
| --- | --- |
| 共同尺度 | 两个水平条形共享 0–100 的起点和尺度 |
| 纯角度 | 两个等半径扇形，无刻度和参考线 |
| 角度改进 | 扇形加入低对比度刻度环和 25%、50%、75% 参考射线 |

被试在输入框中填写 0–100 的整数，并按回车提交。两个目标值、左右位置和较大值所在位置随机化。三种条件使用同一组真实比例，防止材料难度不同。

练习 6 次。正式实验每个条件 12 次，共 36 次。三种显示方式以小区组交错呈现，避免固定的练习或疲劳顺序。

### 5.3 因变量

- 绝对百分比误差。
- 对数误差。
- 判断时间。

计算方法：

```text
绝对误差 = |估计百分比 − 真实百分比|
log error = log2(|估计百分比 − 真实百分比| + 1/8)
```

结果展示以绝对误差为主，对数误差用于与经典研究进行补充比较。

### 5.4 改进思路

纯角度图缺少稳定参照。刻度环和参考射线帮助观察者把角度映射到固定比例区间。该设计可用于仪表、环形进度图和饼图。参考线使用低对比度颜色，避免遮挡数据。

### 5.5 事前预测

**H7，经典效应。** 共同尺度条形的绝对误差小于纯角度条件。

**H8，改进效应。** 角度改进条件的绝对误差小于纯角度条件，但预计仍高于共同尺度条形。

**H9，判断时间预测。** 角度改进条件的判断时间预计短于纯角度条件。考虑到部分被试可能逐格计数，判断时间只作为次要结果，不作为改进成功的唯一标准。

### 5.6 数据字段

```text
trial_index, encoding, value_a, value_b, true_ratio,
estimate, abs_error, log_error, rt
```

后台实验名：`graphical_perception_guides`。

## 六、随机化与平衡规则

- 三个实验的顺序按匿名编号分配到六种顺序。
- 每个实验内部先生成数量完全平衡的试次，再执行随机排列。
- Flanker 每个条件单元的左右目标方向相等。
- 视觉搜索每个条件单元的左右目标方向相等，分组区域左右位置相等。
- 图形比例判断中，较大值的左右位置相等，同一组真实比例在三个显示条件中重复使用。
- 连续相同正确按键不超过 3 次。
- 随机化结果随试次数据保存，确保分析时可以复核。

## 七、数据清理与排除规则

这些规则在正式收数前确定。

### 7.1 记录级处理

- 同一匿名编号重复完成某个实验时，优先使用最后一条完整记录。
- 试次数少于计划数量的记录视为未完成，不进入主要分析，但保留在原始数据中。
- `test_` 前缀的实验记录均属于调试数据，不进入分析。

### 7.2 Flanker 与视觉搜索

- 错误试次不进入反应时分析，保留用于正确率分析。
- 反应时小于 150 ms 的试次视为预按反应，不进入反应时分析。
- 超时试次不进入反应时分析，按错误试次计入正确率。
- 某名被试在单个实验中的总体正确率低于 60% 时，该被试在该实验的结果不进入主要反应时分析，并单独报告。
- 不因反应较慢而直接删除某名被试。

### 7.3 图形比例判断

- 输入框只接受 0–100 的数值，越界值和空值不能提交。
- 判断时间小于 300 ms 的试次标记为异常快速反应，不进入主要分析。
- 页面失焦、刷新或程序错误导致的未完成记录不进入主要分析。

### 7.4 原始数据

- 原始 CSV 下载后只读保存，不直接覆盖。
- 清理后的数据另存，并记录每条排除原因。
- 不手工修改正确答案、反应时、条件或被试编号。

## 八、主要效应与分析计划

### 8.1 Flanker

对每名被试分别计算四个条件的中位反应时和正确率。

```text
普通排列干扰效应 = RT不一致,普通 − RT一致,普通
目标隔离干扰效应 = RT不一致,隔离 − RT一致,隔离
改进收益 = 普通排列干扰效应 − 目标隔离干扰效应
```

改进收益为正时，方向与 H2 一致。

### 8.2 视觉搜索

对每名被试、每种显示方式分别计算集合大小 8 和 24 的中位反应时。

```text
搜索斜率 = (RT24 − RT8) / 16
分组收益 = 混合联合搜索斜率 − 分组联合搜索斜率
```

分组收益为正时，方向与 H5 一致。

### 8.3 图形比例判断

对每名被试分别计算三个显示条件的平均绝对误差、中位绝对误差和判断时间。

```text
角度参照收益 = 纯角度平均绝对误差 − 角度改进平均绝对误差
```

角度参照收益为正时，方向与 H8 一致。

### 8.4 报告方式

- 先报告样本量、有效试次数、条件均值或中位数和个体数据点。
- 使用被试内配对差值展示改进方向。
- 样本达到 5 人时，以描述统计和效应方向为主。
- 若样本达到 10 人，可补充配对检验和置信区间，检验结果作为补充证据。
- 与经典论文比较时，重点比较效应方向和条件排序。刺激、设备和样本不同，不把数值差异直接解释为复现失败。
- 不显著结果只说明当前数据证据不足，不解释为效应不存在。
